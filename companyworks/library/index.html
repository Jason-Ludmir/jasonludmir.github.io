About these collections

ITAC covers industrial energy improvements. CLEAR describes healthcare service redesign. PMC includes articles, reviews, and simulations; 77 records have only short or partial text in the collected material. These records have not all been screened for business-case relevance.

Topic filters are keyword matches and may miss relevant material. CLEAR pages and PDFs can describe the same case, so document counts are not unique-case counts. Search covers titles, institutions, subjects, and document types.

Results link to the publishers’ originals. Source content and reuse terms remain with each publisher. The local downloaded archive is separate from this web catalog.

The separate ITAC assessment database contains 23,022 assessments and 170,726 recommendations in the collected snapshot; those rows are not included in these search results.

Collected October 26, 2026. Sources: ITAC, CLEAR, and PubMed Central.
